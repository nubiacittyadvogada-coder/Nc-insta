# Modelos

`renderer.js` desenha todas as peças a partir do texto, sem depender de Canva:

| Formato | Tamanho | Observação |
|---|---|---|
| Carrossel / post | 1080 × 1350 | capa, meio e encerramento com layouts diferentes |
| Story | 1080 × 1920 | área de 250 px no topo e espaço livre embaixo para figurinhas |
| Capa de Reel | 1080 × 1920 | texto dentro do recorte 1080 × 1350 que aparece no grid |
| Texto do Reel 7s | 1080 × 1920 | PNG transparente para sobrepor ao vídeo |

Estilos: `editorial`, `lifestyle`, `colagem`, `jornalistico`, `minimal`.
Ênfase: escreva `*trecho*` para destacar em itálico/vinho. Fontes (licença OFL): Bodoni Moda, Archivo, Anton, em `fontes/`.
