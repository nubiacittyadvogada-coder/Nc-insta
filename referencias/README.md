# Referências

A biblioteca visual vive no app, em **Minha marca > Biblioteca de referências**. Cada referência recebe etiquetas:

- **Estilo:** Editorial sofisticado, Lifestyle com foto, Colagem criativa, Jornalístico provocativo, Minimalismo tipográfico, Outro
- **Tipografia:** Serifada, Sem serifa, Condensada, Manuscrita, Mista
- **Composição:** Texto central, Foto e texto, Colagem, Grid, Minimal, Jornal
- **Finalidade:** carrossel, story, capa de reel, post, **foto própria autorizada**

Regras:
1. Referência é inspiração. Textos, fotos e layouts de outros criadores não são copiados.
2. Só fotos marcadas como "foto própria autorizada" entram nas artes (estilo lifestyle).
3. Rosto e corpo da Núbia nunca são alterados.
